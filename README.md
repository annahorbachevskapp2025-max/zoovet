## Технології

- HTML5 — семантична розмітка
- Tailwind CSS (Play CDN) — адаптивна верстка mobile-first
- JavaScript (ES6) — валідація, калькулятор, модальне вікно
- Open-Meteo API — інформер погоди у Львові

## Форма зворотного зв'язку (ЛР9)

| Поле | Тип | Правило |
|---|---|---|
| Ім'я | `text` | щонайменше 2 символи, лише літери, пробіл, дефіс, апостроф |
| Email | `email` | формат `ім'я@домен.зона` |
| Телефон | `tel` | `+380` і рівно 9 цифр |
| Повідомлення | `textarea` | щонайменше 10 символів |
| Згода | `checkbox` | має бути позначений |

Валідація відбувається на подію `blur` для кожного поля і повторно для всіх полів
при натисканні «Надіслати». Якщо є хоч одна помилка, відправка блокується
через `event.preventDefault()`, а фокус переходить на перше помилкове поле.

Серверної частини в проєкті немає, тому модальне вікно успіху чесно повідомляє,
що це демонстрація клієнтської валідації.

## Запуск локально

```bash
git clone <URL репозиторію>
cd zoovet
# відкрити index.html у браузері або запустити локальний сервер:
python3 -m http.server 8000
```
